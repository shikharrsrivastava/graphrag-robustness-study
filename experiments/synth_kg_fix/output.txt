You are an expert knowledge graph extraction system. Your task is to extract factual relationships between the provided entity mentions from the text below, returning valid JSON.

9. Return ONLY a valid JSON object matching this schema, with no preamble, markdown code blocks, or extra text:

{
  "relationships": [
    {
      "source_mention_id": "mention_id",
      "target_mention_id": "mention_id",
      "relation_type": "ALLOWED_RELATION_TYPE",
      "evidence_quote": "exact verbatim text from the chunk",

}

     ```python
     adj = collections.defaultdict(set)

         v = rel["target_entity_id"]
